- slime-leaf.png — ศัตรู Slime ใบไม้
- forest-arena.png — ฉากสนามป่าซากปรักหักพัง ภาพทึบ ไม่มี UI/ตัวละคร

ตัวละคร Slime และเอฟเฟกต์เป็น PNG RGBA ตรวจพบ alpha โปร่งใสจริง ฉากเป็น RGB

อาวุธไม่ได้รวมกับตัวละครตามคำขอผู้ใช้

prompts.json เก็บ prompt ที่ใช้; manifest.json เก็บขนาดและขอบเขต alpha เพื่อใช้นำเข้า
