# TILMO — Survivor Idle 2.5D Cartoon

**Game Design Document (GDD) v1.0 — 22 พฤศจิกายน 2026**  
สถานะ: แนวคิดและแผนทดสอบก่อนพัฒนา ไม่ใช่ฟีเจอร์ที่ทำเสร็จแล้ว

## 1. วิสัยทัศน์
TILMO เป็นเกมเว็บ Survivor Roguelite + Idle Progression ภาพ **2.5D Cartoon** สีสดใส ไม่ใช่ Pixel Art และไม่ใช่ MMORPG แบบ RO เล่นได้บนมือถือแนวตั้งและคอมพิวเตอร์แนวนอน เน้นสนุกตั้งแต่เริ่ม เข้าใจง่าย เล่นคนเดียวได้ และมีเป้าหมายให้กลับมาเล่นซ้ำ

**หลักการ:** ผู้เล่นเดินหลบและจัดตำแหน่งเอง โจมตีพื้นฐานอัตโนมัติ เลือกสกิลระหว่างรอบ เปิด Auto ช่วยฟาร์มด่านที่เคยผ่านได้ ส่วนบอส/ด่านใหม่ต้องมีการตัดสินใจและใช้ฝีมือ

## 2. เป้าหมายที่ต้องทดสอบ
- เข้าเล่นได้ภายใน 10 วินาทีหลังโหลดพร้อม
- ได้เลือกอัปเกรดแรกภายใน 30 วินาที
- จบรอบแรกใน 3–5 นาที
- ผู้เล่นใหม่อย่างน้อย 60% เล่นถึง 5 นาที
- อย่างน้อย 40% เริ่มรอบที่สอง
- D1 retention เป้าหมายทดลอง >=30%; D7 >=10%
- เปิดแพ็กสนับสนุนราคาเริ่มต้น **35 บาท** เมื่อความสนุกผ่านการทดสอบแล้ว

ตัวเลขทั้งหมดเป็น **สมมติฐาน/เป้าหมายทดสอบ** ไม่ใช่ผลลัพธ์จริงหรือเกณฑ์อุตสาหกรรมที่ยืนยันแล้ว

## 3. Core Loop
1. กดเล่น → ลงสนามทันที
2. เคลื่อนที่หลบฝูงศัตรู / โจมตีอัตโนมัติ / เก็บ EXP
3. เลเวลอัป → เลือกสกิล 1 จาก 3 ตัวเลือก
4. ผสมสกิลเพื่อปลดล็อก Evolution
5. เจอ Elite และบอส → รับหีบและอุปกรณ์
6. กลับหน้าเตรียมตัว → สวมใส่อุปกรณ์ / อัปเกรด / รับรางวัล Idle
7. ลงรอบใหม่เพื่อทดลอง Build หรือผ่านด่านที่ยากขึ้น

## 4. ประสบการณ์ 30 วินาทีแรก
| เวลา | เหตุการณ์ |
|---|---|
| 0–5 วินาที | ฮีโร่ลงสนาม ไม่บังคับสมัครสมาชิกก่อนทดลอง |
| 5–10 วินาที | มอนสเตอร์ 3–5 ตัวเข้ามา ระบบโจมตีอัตโนมัติเริ่มทำงาน |
| 10–20 วินาที | เก็บ EXP เห็นแถบเลเวลเพิ่มและ Feedback ชัดเจน |
| 20–30 วินาที | หยุดเวลาและให้เลือกสกิล 1 จาก 3 |
| หลัง 30 วินาที | สกิลใหม่แสดงผลทันทีอย่างเห็นได้ชัด |

**ข้อห้าม:** ไม่มีบทสนทนายาว ไม่มีหน้าร้านค้าบังคับ ไม่มีเมนูรกก่อนเริ่มเล่น

## 5. ห้านาทีแรก
- **นาที 1:** ได้สกิลใหม่และทดลองหลบศัตรู
- **นาที 2:** เริ่มเห็นคอมโบสกิล เช่น ลูกไฟแตกกระจาย
- **นาที 3:** เจอ Elite / มินิบอส ได้หีบสมบัติ
- **นาที 4:** เลือกเส้นทางเสี่ยงสูงหรือปลอดภัย
- **นาที 5:** สู้บอสแรก ได้อาวุธถาวรที่เปลี่ยนรูปลักษณ์ตัวละคร

## 6. การควบคุม
| กิจกรรม | มือถือ | คอมพิวเตอร์ |
|---|---|---|
| เดิน 8 ทิศทาง | Virtual joystick | WASD / ลูกศร |
| โจมตีพื้นฐาน | อัตโนมัติ | อัตโนมัติ |
| สกิลพิเศษ | ปุ่มสกิล | Space |
| เลือกอัปเกรด | แตะการ์ด | เมาส์ / ปุ่ม 1–3 |
| หยุดเกม | Pause | Esc |

## 7. ระบบสกิลและคอมโบ
- อาวุธหลักประจำฮีโร่
- สกิลระหว่างรอบที่สุ่มเสนอ 3 ตัวเลือก
- Evolution เมื่อมีคู่สกิลและเงื่อนไขที่กำหนด
- การสุ่มต้องคำนึงถึง Build ที่ผู้เล่นกำลังทำ ไม่ใช่สุ่มจนประกอบคอมโบไม่ได้

**ตัวอย่าง Evolution**
- ดาบ + ไฟ → ดาบเพลิงวน
- ธนู + สายฟ้า → ลูกศรอัสนี
- เกราะ + น้ำแข็ง → เกราะพายุหิมะ
- ลม + ไฟ → พายุอัคคี

MVP: 12 สกิลพื้นฐาน, 6 Evolution

## 8. ศัตรูและบอส
- Slime: เดินเข้าหา
- Runner: เร็วแต่เลือดน้อย
- Archer: โจมตีระยะไกล
- Tank: ช้าแต่ทน
- Summoner: เรียกลูกน้อง
- Elite: มีท่าพิเศษ

บอสแรกมี 3 รูปแบบ: พุ่งเป็นเส้นตรง, ทุบพื้นที่เตือนล่วงหน้า, เรียกลูกน้อง ต้องมี Telegraph ชัดเจนและเปิดโอกาสให้หลบได้จริง

## 9. Idle Progression
แยกสองโหมด:
- **Adventure Run:** ผู้เล่นควบคุม ได้อุปกรณ์หายาก บอส ด่านใหม่ และคอมโบ
- **Idle Camp:** สะสมทอง EXP บางส่วน และวัตถุดิบทั่วไปขณะออฟไลน์ จำกัดสูงสุด 8 ชั่วโมงในเวอร์ชันทดลอง

รางวัลออฟไลน์คำนวณจากเวลาฝั่งเซิร์ฟเวอร์เมื่อกลับเข้าเกม ไม่ต้องจำลองฉากและศัตรูตลอดเวลา และไม่ให้ Idle ปลดล็อกเนื้อหาหลักแทนผู้เล่นทั้งหมด

## 10. ความก้าวหน้าระยะยาว
- **ระหว่างรอบ:** เลเวลและสกิลที่เลือก รีเซ็ตเมื่อจบรอบ
- **ถาวร:** ฮีโร่ อุปกรณ์ การอัปเกรด แผนที่ คอลเลกชัน และแฟชั่น

| ระยะ | เป้าหมาย |
|---|---|
| วันแรก | บอสแรก อาวุธถาวร Idle Camp |
| วันที่ 2–3 | ฮีโร่ตัวที่สอง ทดลอง Build |
| วันที่ 4–7 | พื้นที่ใหม่ อัปเกรดอุปกรณ์ |
| สัปดาห์ 2 | ด่านท้าทายและบอสใหม่ |
| สัปดาห์ 3–4 | Build ขั้นสูง คอลเลกชัน และสถิติ |
| หลังเดือนแรก | เนื้อหาซีซันและด่านใหม่ |

เพิ่ม **Daily Rift** ด่านประจำวันที่ใช้ชุดเงื่อนไขเดียวกัน มีอันดับแบบ Async ไม่ต้องรอคนออนไลน์พร้อมกัน

## 11. Monetization: 35 บาทเริ่มต้น
**TILMO Founder Pack — 35 บาท / บัญชี / ซื้อครั้งเดียว**
- ชุดแฟชั่นถาวร
- เอฟเฟกต์อาวุธตกแต่ง
- กรอบโปรไฟล์ Founder
- สัตว์เลี้ยงตกแต่ง ไม่เพิ่มพลัง

เปิดขายหลังผู้เล่นผ่านบอสแรกและเห็นระบบแฟชั่นแล้ว ไม่บังคับซื้อ ไม่ขายพลังที่เหนือกว่าของฟรีอย่างมีนัยสำคัญ และไม่ขัดจังหวะการต่อสู้ด้วยป๊อปอัป

ภายหลังอาจเพิ่มชุดแฟชั่น 59–99 บาท และ Season Pass แบบ Cosmetic หากมีผู้เล่นกลับมาอย่างสม่ำเสมอ

**ตัวอย่างรายได้สมมติ:** ผู้เล่นใหม่ 1,000 คน × ซื้อ 5% × 35 บาท = 1,750 บาท ก่อนหักค่าใช้จ่าย

## 12. Art Direction / UI
- **ภาพ:** 2.5D Cartoon / Stylized HD, มุมกล้อง Isometric หรือ Top-down เฉียง, ไม่ใช้ Pixel Art
- **บรรยากาศ:** สีสด แฟนตาซีสบายตา ฉากมีมิติ เช่น ป่า ซากปรักหักพัง น้ำตก ประตูเวทมนตร์
- **ตัวละคร:** Cartoon Hero สัดส่วนอ่านง่ายจากมุมกล้อง เปลี่ยนชุด/อาวุธ/สัตว์เลี้ยงเห็นจริง
- **เอฟเฟกต์:** สวยแต่ไม่บดบังศัตรู พื้นที่เตือนบอสต้องเห็นชัด
- **มือถือแนวตั้ง:** แถบ HP/เลเวลด้านบน, เป้าหมาย/เวลาขนาดเล็ก, Joystick ซ้ายล่าง, สกิลและ Auto ขวาล่าง, EXP ด้านล่าง
- **เดสก์ท็อปแนวนอน:** พื้นที่ต่อสู้กินจอเป็นหลัก HUD ตามขอบ ไม่มีเมนูใหญ่บดฉาก
- **HUD:** ลดปุ่มที่ไม่เกี่ยวกับการต่อสู้; ร้านค้า กิลด์ และคอลเลกชันอยู่หน้า Lobby ไม่แสดงทั้งหมดระหว่างเล่น
- **โลโก้/ไอคอน:** คำว่า TILMO, สัญลักษณ์ที่จำได้แม้แสดง 64×64 px, ไม่มีข้อความเล็กใน App Icon

## 13. เทคโนโลยีเบื้องต้น
- เกมเว็บ: ประเมิน Phaser 3 สำหรับ 2D ที่วาดให้ดู 2.5D หรือ Three.js หากต้องการโมเดล 3D จริง
- Backend: Node.js + Express
- Database ต้นแบบ: SQLite (พิจารณาขยายตามภาระงาน)
- บันทึกและตรวจสอบรางวัลถาวรฝั่งเซิร์ฟเวอร์
- Object Pooling, จำกัดจำนวนศัตรู/Particle, Adaptive Quality, ทดสอบ Chrome บนอุปกรณ์ RAM 4 GB

**การเลือก Engine ต้องทำ Prototype ประสิทธิภาพก่อน** เพราะภาพ 2.5D อาจหมายถึงภาพ 2D Isometric หรือฉาก 3D จริง ซึ่งมีต้นทุนต่างกัน

## 14. MVP / Roadmap สำหรับ AI Coding
### Milestone 1: Combat Prototype
ฮีโร่ 1 ตัว, ศัตรู 6 ชนิด, บอส 1 ตัว, 12 สกิล, 6 Evolution, แผนที่ 1 ฉาก, รอบ 5 นาที

### Milestone 2: Fun & Balance
ปรับจังหวะ EXP, ความหนาแน่นศัตรู, สกิล, ความยาก, เสียง, การตอบสนอง; ทดสอบผู้เล่นจริง 20–30 คน

### Milestone 3: Progression
อุปกรณ์ 15 ชิ้น, เซฟความก้าวหน้า, อัปเกรด, Idle Camp, ระบบบัญชี

### Milestone 4: Visual & Performance
ภาพ Cartoon 2.5D, HUD มือถือ/คอม, การเปลี่ยนชุด, โหมดประหยัดทรัพยากร

### Milestone 5: Monetization
ร้านค้า, Founder Pack 35 บาท, ตรวจสอบการชำระเงินและการให้ไอเท็มอย่างปลอดภัย

## 15. สิ่งที่ไม่ทำใน MVP
Open World, เควสต์ NPC จำนวนมาก, ระบบกิลด์ซับซ้อน, PvP แบบต้องรอจับคู่, อาชีพจำนวนมาก, Pay-to-Win, ระบบเติมเงินก่อนพิสูจน์ความสนุก
