# TILMO — Survivor Idle 2.5D Cartoon

สถานะ: Combat Prototype v0.1 • 22 พฤศจิกายน 2026 • เริ่มพัฒนาแล้วตามคำขอผู้ใช้

เกมใหม่อยู่ในโฟลเดอร์นี้ แยกจาก `../gm` (ตำนาน 3 อัศวิน) ไม่ใช่การเปลี่ยนภาพทับเกมเดิม

## ข้อตกลงจากคำขอผู้ใช้
- พักการพัฒนาเกมเก่าไว้ก่อน ไม่แก้โค้ดหรือย้ายข้อมูลเก่าในงานนี้
- ออกแบบ TILMO ใหม่เป็น Survivor Idle ภาพ Cartoon 2.5D
- วางแผนก่อนลงมือพัฒนา เพื่อพิสูจน์ว่าผู้เล่นอยากเล่นซ้ำ
- ยังไม่ได้สั่งปิดเซิร์ฟเวอร์เกมเก่า และงานนี้ไม่ได้เปลี่ยน deployment

## เล่นต้นแบบ

ต้องมี Node.js 22+ ไม่ต้องติดตั้ง dependencies

```sh
npm run dev
```

เปิด http://localhost:5174 (ใช้พอร์ตแยกจากเกมเก่า)
WASD/ลูกศร หรือแตะลากบนสนามเพื่อเดิน โจมตีและสกิลอัตโนมัติ กด 1–3/แตะเลือกอัปเกรด Esc เพื่อพัก เมื่อสลับแท็บเกมพักอัตโนมัติ

มีศัตรู 3 แบบ, Elite, บอสเริ่มนาที 4, จบรอบไม่เกิน 5 นาที, สกิล 4 แบบ/passive 2 แบบ และ Evolution 2 สูตรแล้ว ภาพเป็นการ์ตูนวาดด้วย Canvas สำหรับทดสอบระบบ ยังไม่ใช่งาน HD ตามภาพอ้างอิง ไม่มีบัญชี/Idle/ร้านค้า/เซฟอุปกรณ์ถาวร

สถิติรอบที่จบเก็บใน localStorage สูงสุด 20 รอบ ส่งออก JSON จากหน้าผลรอบได้ ยังไม่มีการส่ง analytics ไปเซิร์ฟเวอร์ และยังไม่เก็บการออกกลางรอบ จึงยังวัดอัตราทิ้งเกม/D1/D7 ไม่ได้

ตรวจระบบด้วย `npm run check` และ `npm test` ก่อนนำให้คนทดลอง ดูรายละเอียดผลตรวจใน [IMPLEMENTATION.md](docs/IMPLEMENTATION.md)

## ฮีโร่และอาชีพ Lv.10

เริ่มฝึกหัดทันที ถึง Lv.10 ครั้งแรกค่อยเลือกอาชีพ 3 แบบและรูปลักษณ์ชาย/หญิง จำไว้เฉพาะเครื่องนี้ รอบใหม่ยังเริ่ม Lv.1 แต่คงอาชีพที่เลือกไว้ ดูรายละเอียด [AWAKENING.md](docs/AWAKENING.md) และดูภาพตัวอย่างอาชีพได้จากหน้าเริ่มเกม

## Sprite animation v0.2

เกมใช้ชุดภาพชาย–หญิงยืน/วิ่ง 8 ทิศจริงแล้ว รวม 192 เฟรม (วิ่ง 8 เฟรม/ทิศ) แต่ละช่อง 256×256 และจุดยึดเท้า (128,224) อาวุธแยกชั้นจากภาพตัวละคร

[Sprite Lab](http://localhost:5174/sprite-lab.html) ดูชาย/หญิง ยืน/วิ่ง และทีละเฟรมได้
รัน `npm run import-sprites` เพื่อจัด atlas ใหม่จากต้นฉบับ (ต้องมี Python + Pillow)
รายละเอียดแอนิเมชัน: [SPRITES.md](docs/SPRITES.md) • พรอมป์ต์ภาพที่ช่วยเจนได้: [ART_PROMPTS.md](docs/ART_PROMPTS.md)

อัปเดต v0.3: เก็บจังหวะลอยตัวของการวิ่ง ผูกเฟรมกับระยะเดิน และขยายภาพในเกมบนมือถือ พร้อมรองรับ canvas จอความหนาแน่นสูง ดูเหตุผลและผลตรวจใน docs/SPRITES.md

อัปเดต v0.4: เปลี่ยนชุดวิ่งตาม pose guide และจัดจุดยึดลำตัวใหม่ มีโหมดช้า 1/4 และแผงเทียบทั้งรอบใน Sprite Lab รายละเอียดและพรอมป์ต์อยู่ใน docs/SPRITES.md

## ป่าและกล้อง v0.5

นำฉากป่าและ Slime เข้าเกมแล้ว พร้อมขอบเขตเดินจริง กล้องเริ่มต้นกว้างขึ้น และปุ่ม −/+ มุมขวาล่างสำหรับปรับเอง ดูขอบเขตและผลตรวจใน [FOREST_SLICE.md](docs/FOREST_SLICE.md)

## ทิศทางภาพใหม่

ยึดภาพอ้างอิงล่าสุดเป็นโลกเกาะลอยฟ้าและเทคโนโลยีคริสตัล หน้าเริ่มเกมและสี UI ปรับแล้ว ส่วนภาพในสนามทยอยเปลี่ยนตาม [ART_DIRECTION.md](docs/ART_DIRECTION.md) กล้องเริ่มต้นยังเป็น 60%

## ความลื่น v0.7

ลดการวาดและกรองภาพซ้ำ หยุดวาดฉากระหว่างเมนู/พัก และใช้พิกัดย่อยเมื่อเดินที่ซูม 60% ผลฉากควบคุม 95 ตัววัดได้ 53.7 → 75 FPS ใน browser ที่ทดสอบ รายละเอียดและขอบเขตการวัด: [PERFORMANCE.md](docs/PERFORMANCE.md)
เปิด `http://localhost:5174/?perf=1` เพื่อดูตัววัดเฟรมขณะเล่น (เกมปกติไม่แสดง)

## อาชีพและอาวุธ v0.8

เปิดตัวด้วย 3 อาชีพเท่านั้น: นักดาบ นักเวท มือปืน (ไม่มีนักธนู นักบวช โจร) แต่ละอาชีพมีสกิลของตัวเอง 3 แบบ และอาวุธ 6 ระดับ (Common→Mythic) ที่อัปเกรดระหว่างเล่น โค่นบอสแล้วขึ้นด่านถัดไปแทนการจบเกม และแก้ท่าวิ่งกระตุก ดู [CLASSES.md](docs/CLASSES.md)
