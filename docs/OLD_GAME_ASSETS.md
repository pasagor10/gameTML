# ของที่ยืมจากเกมเดิม (ชั่วคราว) — v0.10

22 พฤศจิกายน 2026 • ผู้ใช้อนุญาตให้นำเสียง มอนสเตอร์ และอาวุธจากเกมเดิม (../gm) มาใช้ก่อน แล้วค่อยทำใหม่ภายหลัง
ไม่ได้แก้ไฟล์ใดในเกมเดิม เป็นการคัดลอกเข้ามาในโฟลเดอร์ TILMO เท่านั้น

## เสียง
- src/sound.js คัดลอกจาก gm/public/sound.js (WebAudio + ไฟล์ CC0) เปลี่ยน key ตั้งค่าเป็น tilmo-sound / tilmo-music และเพิ่มเสียงยิงปืน `shot` แบบสังเคราะห์ (ชุด CC0 ไม่มีเสียงปืน)
- assets/sfx/*.mp3 (30 ไฟล์) และ assets/music/{town.mp3, battle.mp3, boss-epic.ogg} พร้อม CREDITS.md เดิม — ทั้งหมดเป็น CC0 ตามที่บันทึกไว้
- เพลง: หน้าแรก town • ในสนาม battle • ตอนบอส boss-epic • จบรอบเงียบ
- โมเดลส่ง `cues` (ฟัน/ยิง/ร่าย/โดน/ตาย/เก็บคริสตัล/เลเวลอัป/บอสคำราม/บอสกระแทก/ขึ้นด่าน/อาวุธอัปเกรด) ให้ game.js เล่นเสียง โมเดลจึงยังทดสอบได้โดยไม่มีเสียง
- ปุ่ม ♪ มุมขวาบนเปิด/ปิดทั้งเสียงและเพลง (ค่าเริ่มต้นเปิด เบราว์เซอร์จะเริ่มเสียงหลังแตะ/กดครั้งแรก)

## มอนสเตอร์ (pixel art เกมเดิม)
src/monsters.js โหลด assets/monsters/old/<ชื่อ>/{move,attack} — Slime ยังใช้ภาพวาดของ TILMO
| บทบาท TILMO | ภาพเกมเดิม |
|---|---|
| Runner | wolf (ด่านคี่), bat (ด่านคู่) |
| Archer | goblin, mushroom |
| Elite | boar → golem → frost-scarab → storm-roc วนตามด่าน |
| บอส | thorn-queen → ember-colossus → frost-revenant → yaksha → moon-emperor วนตามด่าน พร้อมชื่อไทยบนแถบเลือดบอส |
ตอนมีวงเตือนจะใช้ท่า attack, หันหน้าหาผู้เล่น, โดนตีจะสว่างวาบ • ขนาดชนเท่าเดิม เปลี่ยนแค่ภาพ
