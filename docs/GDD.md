# 1. ภาพรวมโครงการ (Game Overview)

## 1.1 แนวคิดหลัก

เกม MMORPG สไตล์ Chibi Fantasy 2D Side-Scrolling ที่ผู้เล่นสามารถเดิน กระโดด ต่อสู้ พูดคุย ซื้อขาย แลกเปลี่ยนไอเทม และร่วมทีมกับผู้เล่นอื่นได้แบบ Real-time

เรื่องราวเกิดขึ้นบริเวณเทือกเขาดอยนางนอน จังหวัดเชียงราย โดยนำตำนานท้องถิ่นมาดัดแปลงเป็นโลกแฟนตาซี มีดันเจียนลึกลับ 100 ชั้นซ่อนอยู่ภายในถ้ำหลวง

ผู้เล่นรับบทเป็นหนึ่งในสามสายอาชีพ เพื่อผจญภัยผ่านดันเจียนและค้นหาความลับที่อยู่ชั้นสูงสุด

## 1.2 จุดเด่นของเกม

1. แผนที่กลางที่ผู้เล่นสามารถพบปะกันได้
2. ตัวละคร Chibi 2 เพศ 3 อาชีพ
3. ดันเจียน 100 ชั้น ชั้นละ 3 ด่าน
4. ระบบต่อสู้ Manual และ Auto
5. ระบบปาร์ตี้สูงสุด 3 คน
6. ร้านค้าผู้เล่นและระบบแลกเปลี่ยน
7. ระบบอัปเกรดอาวุธและอุปกรณ์
8. ระบบไอเทมและเศรษฐกิจภายในเกม
9. รองรับการเล่นผ่านเว็บทั้ง PC และมือถือ

## 1.3 ขอบเขตการพัฒนา

**Demo v0.1**
- เมืองกลาง 1 แผนที่
- ดันเจียน 3 ชั้น รวม 9 ด่าน
- ตัวละคร 6 แบบ
- อาชีพ 3 อาชีพ
- มอนสเตอร์อย่างน้อย 6 ชนิด และบอส 3 ชนิด
- NPC 4 ตัว
- ระบบร้านค้าและแลกเปลี่ยน
- Multiplayer, Chat, Party
- Auto / Manual Battle

**Full Game**
- ดันเจียน 100 ชั้น รวม 300 ด่าน
- อุปกรณ์และมอนสเตอร์เพิ่มตามระดับ
- ระบบ Guild, World Boss, Event และ Ranking ในอนาคต

# 2. เนื้อเรื่อง (Story)

## 2.1 ตำนานถ้ำหลวง

หลายร้อยปีก่อน มีตำนานเล่าขานว่าใต้เทือกเขาดอยนางนอนมีประตูเชื่อมต่อโลกมนุษย์กับดินแดนแห่งวิญญาณ

ภายในถ้ำหลวงมีหอคอยใต้พิภพที่ประกอบด้วย 100 ชั้น แต่ละชั้นถูกปกป้องด้วยมอนสเตอร์และผู้พิทักษ์โบราณ

วันหนึ่งพลังลึกลับเริ่มรั่วไหลออกจากถ้ำ ทำให้สัตว์ป่ากลายเป็นปีศาจ และหมู่บ้านรอบภูเขาตกอยู่ในอันตราย

ผู้กล้าสามสายอาชีพจึงถูกเรียกตัวมาเพื่อค้นหาต้นตอของพลังดังกล่าว

## 2.2 เป้าหมายของผู้เล่น

- สำรวจถ้ำหลวง
- กำจัดมอนสเตอร์และบอส
- รวบรวมอุปกรณ์ที่แข็งแกร่งขึ้น
- เปิดเส้นทางไปยังชั้นถัดไป
- ร่วมมือกับผู้เล่นอื่น
- พิชิตผู้พิทักษ์ชั้นที่ 100

## 2.3 การแบ่งเนื้อเรื่อง

| ชั้น | บท | ธีม |
|---|---|---|
| 1–10 | ปากถ้ำต้องคำสาป | ถ้ำธรรมชาติ |
| 11–20 | ป่าใต้พิภพ | ป่าเรืองแสง |
| 21–30 | อาณาจักรหิน | ซากเมืองโบราณ |
| 31–40 | ทะเลสาบวิญญาณ | ถ้ำน้ำ |
| 41–50 | หุบเหวเพลิง | ลาวา |
| 51–60 | วิหารแห่งเงา | วิหารมืด |
| 61–70 | อาณาจักรน้ำแข็ง | ถ้ำน้ำแข็ง |
| 71–80 | ดินแดนปีศาจ | ป้อมปีศาจ |
| 81–90 | ประตูแห่งเทพ | วิหารลอยฟ้า |
| 91–100 | บัลลังก์ผู้พิทักษ์ | ดันเจียนสุดท้าย |

# 3. ระบบตัวละคร (Character System)

## 3.1 การสร้างตัวละคร

ผู้เล่นต้องสมัครสมาชิกและเข้าสู่ระบบก่อนสร้างตัวละคร

สามารถเลือก:
- เพศชายหรือหญิง
- ชื่อตัวละคร (ไม่ซ้ำกัน)
- อาชีพ
- ทรงผมและสีผมเบื้องต้น

หนึ่งบัญชีมีตัวละครได้สูงสุด 3 ตัวใน Demo

## 3.2 อาชีพ

### นักดาบ (Swordsman)
- อาวุธหลัก: ดาบ
- HP สูง
- ป้องกันสูง
- โจมตีระยะประชิด

สกิลเริ่มต้น:
1. Sword Slash — ฟันศัตรูด้านหน้า
2. Power Strike — โจมตีรุนแรง
3. Blade Wave — ปล่อยคลื่นดาบ

### นักธนู (Archer)
- อาวุธหลัก: ธนู
- ความเร็วโจมตีสูง
- โจมตีระยะไกล
- HP ปานกลาง

สกิลเริ่มต้น:
1. Quick Shot — ยิงธนูเร็ว
2. Double Arrow — ยิงสองดอก
3. Arrow Rain — ยิงธนูเป็นพื้นที่

### จอมเวท (Mage)
- อาวุธหลัก: คทา
- พลังเวทสูง
- โจมตีเป็นพื้นที่
- HP ต่ำ

สกิลเริ่มต้น:
1. Magic Bolt — ลูกพลังเวท
2. Fire Ball — ลูกไฟ
3. Ice Storm — พายุเยือกแข็ง

## 3.3 ค่าสถานะ

- HP — พลังชีวิต
- MP — พลังเวท
- ATK — พลังโจมตีกายภาพ
- MATK — พลังโจมตีเวท
- DEF — พลังป้องกัน
- CRIT — โอกาสโจมตีคริติคอล
- ASPD — ความเร็วโจมตี
- MOVE — ความเร็วเคลื่อนที่

ค่าพลังเริ่มต้น อัตราเพิ่มตามเลเวล และสูตรคำนวณความเสียหายจะเก็บเป็นข้อมูล Configuration ที่ Server ควบคุม

## 3.4 ระบบเลเวล

- เริ่มต้น Level 1
- Demo รองรับถึง Level 40
- Full Game ตั้งเป้าสูงสุด Level 100
- ได้ EXP จากการกำจัดมอนสเตอร์และเควส
- เพิ่มค่าสถานะตามอาชีพเมื่อเลเวลเพิ่ม
- เมื่อตายจะกลับจุดเกิด โดย Demo ไม่หัก EXP

# 4. ระบบแผนที่ (World Map)

## 4.1 เมืองกลาง — เมืองหน้าถ้ำหลวง

เป็นแผนที่ Side-Scrolling ที่มีแพลตฟอร์มหลายระดับ ผู้เล่นสามารถเดิน กระโดด และปีนบันไดได้

องค์ประกอบ:
- จุดเกิดผู้เล่น
- ร้านขายยา
- ร้านขายอาวุธ
- ช่างตีบวก
- หัวหน้าหมู่บ้าน
- พื้นที่ตั้งร้านผู้เล่น
- จุดรวมปาร์ตี้
- ประตูเข้าดันเจียน
- กล่องแชตและ Mini-map

## 4.2 ระบบ Channel

เมืองกลางแบ่ง Channel เพื่อรองรับผู้เล่นจำนวนมาก

สำหรับ Demo กำหนดเป้าหมายทดสอบ 20–30 ผู้เล่นต่อ Channel โดยต้องทดสอบประสิทธิภาพจริงก่อนยืนยันจำนวนสูงสุด

ผู้เล่นต่าง Channel จะไม่เห็นกัน แต่สามารถเลือกเปลี่ยน Channel ได้

# 5. ระบบดันเจียน (Dungeon System)

## 5.1 โครงสร้าง

ดันเจียนทั้งหมด 100 ชั้น แต่ละชั้นมี 3 ด่าน

**ด่านที่ 1 — Monster Stage**
- กำจัดมอนสเตอร์ตามจำนวนที่กำหนด
- รับ EXP และไอเทม

**ด่านที่ 2 — Elite Stage**
- พบมอนสเตอร์แข็งแกร่งขึ้น
- มีโอกาสได้รับไอเทมที่ดีกว่า

**ด่านที่ 3 — Boss Stage**
- ต่อสู้กับบอสประจำชั้น
- รับรางวัลพิเศษ
- ปลดล็อกชั้นถัดไป

## 5.2 การปลดล็อก

- ผู้เล่นเริ่มจากชั้น 1
- ต้องผ่านบอสเพื่อปลดล็อกชั้นถัดไป
- สามารถกลับไปเล่นชั้นที่เคยผ่านได้
- ความคืบหน้าบันทึกแยกตามตัวละคร
- ปาร์ตี้ต้องเลือกชั้นที่สมาชิกทุกคนมีสิทธิ์เข้า

## 5.3 Dungeon Instance

แต่ละปาร์ตี้มีห้องดันเจียนของตัวเอง

- Solo: 1 คน
- Party: 2–3 คน
- Server สร้าง Instance เมื่อเข้าดันเจียน
- สมาชิกใน Instance เห็นมอนสเตอร์ชุดเดียวกัน
- มอนสเตอร์และรางวัลคำนวณฝั่ง Server
- Instance ปิดเมื่อสมาชิกออกหมดหรือหมดเวลาที่กำหนด

## 5.4 ตัวอย่าง Demo

| ชั้น | เลเวลแนะนำ | ธีม | บอส |
|---|---|---|---|
| 1 | 1–10 | ปากถ้ำ | ราชาค้างคาว |
| 2 | 10–20 | ถ้ำหินเรืองแสง | ผู้พิทักษ์หิน |
| 3 | 20–30 | โพรงน้ำใต้ดิน | อสรพิษถ้ำ |

ตัวเลขเลเวลและมอนสเตอร์เป็นค่าเริ่มต้นสำหรับปรับสมดุล

# 6. ระบบต่อสู้ (Combat)

## 6.1 Manual Mode

PC:
- A / D — เดิน
- Space — กระโดด
- J — โจมตี
- Q / W / E — ใช้สกิล
- R — ใช้ยา
- F — โต้ตอบ NPC

มือถือ:
- Virtual Joystick
- ปุ่มกระโดด
- ปุ่มโจมตี
- ปุ่มสกิล
- ปุ่ม Auto

## 6.2 Auto Mode

เมื่อเปิด Auto ตัวละครจะ:
1. ค้นหามอนสเตอร์ในระยะ
2. เดินเข้าหาตำแหน่งที่โจมตีได้
3. โจมตีปกติ
4. ใช้สกิลตาม Cooldown และ MP
5. ใช้ยาเมื่อ HP ต่ำกว่าเกณฑ์
6. เปลี่ยนเป้าหมายเมื่อมอนสเตอร์ตาย
7. เข้าด่านถัดไปเมื่อผ่านเงื่อนไข

ผู้เล่นสามารถปิด Auto ได้ตลอดเวลา

Auto จะทำงานเฉพาะเมื่อผู้เล่นอยู่ในดันเจียนและเชื่อมต่อเกมอยู่เท่านั้นใน Demo ไม่ใช่ระบบฟาร์มขณะ Offline

## 6.3 หลักการคำนวณ

Server เป็นผู้ตัดสิน:
- ตำแหน่งและระยะโจมตี
- Cooldown
- ความเสียหาย
- HP/MP
- การตาย
- EXP
- Item Drop

Client มีหน้าที่รับ Input แสดง Animation และแสดงผลสถานะที่ Server ยืนยัน

# 7. ระบบไอเทม (Item System)

## 7.1 ประเภทไอเทม

- Weapon — อาวุธ
- Armor — ชุดเกราะ
- Accessory — เครื่องประดับ
- Potion — ยา HP/MP
- Material — วัตถุดิบ

## 7.2 ระดับความหายาก

| ระดับ | สี |
|---|---|
| Common | ขาว |
| Uncommon | เขียว |
| Rare | ฟ้า |

| Legendary | ทอง |

- เริ่มต้น 40 ช่อง

- Quest Item ไม่สามารถแลกเปลี่ยนได้

# 8. ระบบ NPC

## 8.1 ร้านขายยา

จำหน่าย:
- Small HP Potion
- Medium HP Potion
- Small MP Potion
- Medium MP Potion

## 8.2 ร้านขายอาวุธ

จำหน่าย:

- ธนูเริ่มต้น
- คทาเริ่มต้น
- ชุดเกราะพื้นฐาน

## 8.3 ช่างตีบวก

ผู้เล่นเลือกอุปกรณ์และจ่ายเงินพร้อมวัตถุดิบเพื่ออัปเกรด

ระดับสูงสุดใน Demo คือ +10

โอกาสสำเร็จและค่าธรรมเนียมกำหนดจาก Server Configuration และบันทึกผลทุกครั้ง

## 8.4 หัวหน้าหมู่บ้าน

ทำหน้าที่:
- แนะนำเนื้อเรื่อง
- แจกเควสเริ่มต้น
- อธิบายการเข้าดันเจียน
- แสดงความคืบหน้าการผจญภัย

# 9. ระบบเศรษฐกิจและซื้อขาย

## 9.1 สกุลเงิน

ใช้สกุลเงินภายในเกมชื่อ **Gold**

ได้รับจาก:
- กำจัดมอนสเตอร์
- ทำเควส
- ขายไอเทมให้ NPC
- ขายสินค้าให้ผู้เล่นอื่น

Demo ไม่มีระบบเติมเงินจริง

## 9.2 ร้านค้าผู้เล่น (Player Shop)

- ตั้งร้านได้เฉพาะในพื้นที่ที่กำหนดของเมืองกลาง
- ตั้งชื่อร้าน
- เลือกไอเทมจาก Inventory
- กำหนดราคา Gold
- ผู้เล่นอื่นสามารถกดดูและซื้อได้
- รองรับ Offline Shop
- จำกัดหนึ่งร้านต่อบัญชี
- ร้านต้องมีพื้นที่แสดงผลที่ไม่ทับร้านอื่น

เมื่อวางขาย ไอเทมจะถูกย้ายเข้า Shop Escrow ของ Server เพื่อป้องกันการนำไอเทมเดียวกันไปขายซ้ำ

## 9.3 ระบบแลกเปลี่ยน (Trade)

ขั้นตอน:
1. ผู้เล่น A ส่งคำขอแลกเปลี่ยน
2. ผู้เล่น B ตอบรับ
3. ทั้งสองฝ่ายวางไอเทมและ Gold
4. ทั้งสองฝ่ายเห็นรายการที่จะได้รับ
5. กดยืนยันครั้งแรก
6. แสดงหน้าตรวจสอบสุดท้าย
7. ทั้งสองฝ่ายยืนยันอีกครั้ง
8. Server โอนสินทรัพย์ใน Transaction เดียว

หากมีการแก้รายการ ต้องยกเลิกสถานะยืนยันทั้งหมด

## 9.4 ความปลอดภัยเศรษฐกิจ

- ห้ามยอด Gold ติดลบ
- ห้ามขายไอเทมที่ไม่มีอยู่จริง
- ห้ามแลกเปลี่ยนไอเทมที่ถูกล็อก
- ใช้ Database Transaction
- บันทึกประวัติทุกการโอน
- ป้องกันคำขอซ้ำด้วย Transaction ID
- Server ตรวจสอบยอดเงินและเจ้าของไอเทมก่อนทำรายการ

# 10. ระบบ Multiplayer

## 10.1 ระบบผู้เล่นออนไลน์

- แสดงผู้เล่นที่อยู่แผนที่และ Channel เดียวกัน
- แสดงชื่อ เลเวล อาชีพ และ Animation
- ส่งตำแหน่งผ่าน Socket.IO
- ใช้ Interpolation เพื่อให้การเคลื่อนไหวลื่นไหล

# 14. แผนพัฒนา (Development Roadmap)

## Phase 1 — Game Foundation
- สร้างโปรเจกต์ Client และ Server
- ระบบ Login
- ระบบสร้างตัวละคร
- เมืองกลาง
- เดิน กระโดด และกล้องติดตาม
- Multiplayer Movement

**เกณฑ์ผ่าน:** ผู้เล่นสองบัญชีเข้าเมืองเดียวกันและเห็นการเคลื่อนไหวของกันและกันได้

## Phase 2 — Combat
- มอนสเตอร์
- ระบบ HP/MP
- ระบบโจมตี
- สกิล 3 อาชีพ
- EXP และ Level
- Item Drop
- Auto Battle

**เกณฑ์ผ่าน:** ผู้เล่นสามารถต่อสู้และรับรางวัลได้โดย Server ตรวจสอบทุกครั้ง

## Phase 3 — Dungeon
- ดันเจียนชั้น 1–3
- ชั้นละ 3 ด่าน
- Boss
- Dungeon Instance
- ระบบปลดล็อกชั้น
- Party Dungeon

**เกณฑ์ผ่าน:** ผู้เล่นผ่านทั้ง 9 ด่านได้ และความคืบหน้ายังคงอยู่หลัง Logout

## Phase 4 — Economy
- Inventory
- Equipment
- NPC Shop
- Enhancement
- Player Shop
- Offline Shop
- Player Trade

**เกณฑ์ผ่าน:** การซื้อขายและแลกเปลี่ยนไม่ทำให้ Gold หรือไอเทมสูญหายหรือเพิ่มซ้ำ แม้เกิดการตัดการเชื่อมต่อ

## Phase 5 — Polish & Testing
- ปรับภาพและ Animation
- ปรับ UI มือถือ
- เสียงและเอฟเฟกต์
- ทดสอบ Multiplayer
- ทดสอบการโหลด
- ทดสอบช่องโหว่เศรษฐกิจ
- ปรับสมดุลเกม

**เกณฑ์ผ่าน:** Demo สามารถเล่นครบวงจรตั้งแต่สมัครสมาชิกจนถึงผ่านบอสชั้น 3
