# Combat Prototype v0.1 — 22 พฤศจิกายน 2026

ผู้ใช้ยืนยันสนามเดินอิสระตามภาพ 4–5 และให้เริ่มระบบก่อน โดยเน้น 30 วินาทีแรก

## ทำงานแล้ว
- Runtime แยก ไม่มี dependencies พอร์ต 5174 ไม่ใช้เซฟ/process เกมเก่า
- สนามเดินอิสระ ขอบเขตโลก คีย์บอร์ด/ลากบนจอ กล้องตามตัวละคร และเรียงวัตถุตามความลึก
- ดาบอัตโนมัติ, Slime/Runner/Archer, เก็บ EXP, หยุดเลือกการ์ด 1 ใน 3
- คริสตัลใกล้ผู้เล่นวินาที 8 และตัวเลือกแรกเป็นสกิลโจมตีทั้งหมด
- สกิล Fire/Ice/Spark/Gust และ passive Area/Haste; จำกัดสกิลเชิงรุก 2 ช่อง; Evolution 2 สูตร
- Elite เริ่มวินาที 100, บอสวินาที 240 พร้อมวง/เส้นเตือน, จบเมื่อชนะ/ตาย/ครบ 300 วินาที
- Pause/สลับแท็บหยุดเวลา, หน้าผลรอบ, เล่นใหม่ และส่งออกสถิติ JSON
- เสียงสังเคราะห์ เปิดได้ด้วยปุ่มเสียง; localStorage เก็บ 20 รอบล่าสุดที่จบ

## ผลตรวจ
`npm run check` ผ่าน และ `npm test` ผ่าน 7 ข้อ ครอบคลุมเวลาการอัปเกรดแรก, pause, ความเร็วเดิน, ขอบเขตโลก, จำนวนช่อง/การ์ด, Evolution, invulnerability, จบรอบครั้งเดียว, บอส/timeout, fallback และสกิลทั้ง 4

ทดลอง simulation ด้วย 5 seed และเส้นทางเดินวงกลม: อัปเกรดแรกประมาณ 8.15–8.25 วินาที มีทั้งแพ้และชนะก่อนครบ 5 นาที เป็น bot simulation ไม่ใช่ผลผู้เล่นจริง และไม่ใช้ยืนยัน balance/retention
เบราว์เซอร์จริงตรวจเข้าเล่นและเห็นการ์ดแรกที่ 00:08; ตรวจเลือก Fire/Ice แล้ว HUD เปลี่ยนและเห็นเอฟเฟกต์, เดินด้วยปุ่ม D, ตรวจ layout แนวตั้ง/แนวนอนที่ 390×844 และ 1280×800 โดยไม่พบ console error ในการตรวจครั้งนี้; รายละเอียดหน้าจอเก็บเป็นภาพใน output

## ข้อจำกัด
ภาพเป็น Canvas vector cartoon สำหรับทดสอบระบบ ยังไม่ใช่ asset HD ตามภาพ 4–5; วัตถุหิน/ต้นไม้ตกแต่งยังไม่มี collision; ไม่มีเซฟอุปกรณ์ถาวร, Idle, บัญชี, backend รางวัล หรือชำระเงิน
การบันทึก event ยังเป็น local ต่อรอบที่จบ ไม่มี exit tracking รวมผู้เล่นจริง ไม่สามารถคำนวณ dropout/D1/D7 ได้
ยังไม่วัด FPS บนมือถือ Android จริง และยังไม่ทดสอบ playtest 5 คน ไม่อ้างว่าบรรลุ retention

## ขั้นถัดไปหลังลองเล่น
ให้ผู้เล่นใหม่ 5 คนลองโดยไม่อธิบาย ดูการเดิน/เข้าใจ EXP/เลือกพลังและเริ่มรอบสอง เก็บคำอธิบายสาเหตุแพ้ ปรับจังหวะตามผล ก่อนเพิ่มระบบถาวรและผลิตงานภาพครบชุด
