# TILMO — Crystal Frontier / ทิศทางภาพใหม่

ผู้ใช้กำหนดจากภาพอ้างอิงวันที่ 22 พฤศจิกายน 2026: เกมต้องมีตัวตนใหม่ ไม่ให้ความรู้สึกเหมือน RO
ภาพอ้างอิงหลักเก็บที่ references/tilmo-crystal-style-reference.png ใช้เป็นทิศทาง ไม่ใช่ข้อกำหนดว่าทุกสิ่งในภาพมีในเกมแล้ว

## ตัวตนหลัก
การ์ตูนแฟนตาซีสีสด ผสมเทคโนโลยีคริสตัล โลกเกาะลอยฟ้าและซากเครื่องจักรโบราณ ฮีโร่เป็นนักสำรวจพลังงาน ไม่ใช่การจำลองเมือง/อาชีพ/มอนสเตอร์ของเกมอื่น

| ส่วน | มาตรฐานใหม่ |
|---|---|
| ฮีโร่ | ผมเงิน แว่นคริสตัล ผ้าพันคอแดง ถุงมือกลไกมีวงจรฟ้า ชุดคล่องตัว วัสดุสังเคราะห์และชิ้นเกราะเบา |
| คู่หู | หุ่นลอยตัวเล็ก มีหน้าจอแสดงอารมณ์ เป็นเอกลักษณ์ในอนาคต ไม่ใช่ระบบที่เปิดใช้งานแล้ว |
| ศัตรู | ตัวเล็กทรงชัด แกนพลังงาน/ใบหน้าดำมีตาสว่าง เช่น Crystal Slime, เห็ดคริสตัล, โดรนป่าร้าง |
| บอส | ผู้พิทักษ์หินผสมเครื่องจักร มีจุดพลังงานและส่วนที่อ่านท่าโจมตีได้ชัด |
| โลก | ท้องฟ้าสีฟ้า เกาะลอย น้ำตก ประตูพลังงาน ซากโครงสร้างที่เชื่อมกับธรรมชาติ |
| สี | ฟ้าเข้มและ cyan เป็นพลังหลัก ขาวเงินเป็นฮีโร่ เขียวสดเป็นธรรมชาติ ทองใช้แต้มเล็กน้อย แดงผ้าพันคอเป็นจุดจำ |
| UI | แผงสีน้ำเงินเข้ม เส้นพลังงานฟ้า รูปทรงเครื่องมือสำรวจ อ่านง่าย ไม่ใช้กรอบทองโบราณทุกหน้าจอ |
| สกิล | คลื่นคริสตัล โดรนวงโคจร ลำแสง และวงจรพลังงาน พื้นที่เตือนศัตรูยังต้องแยกจากเอฟเฟกต์ผู้เล่น |

## การเล่นที่คงไว้
Survivor เล่นรอบสั้น เดินเอง โจมตีอัตโนมัติ เลือก Build ระหว่างรอบ → ลองรอบใหม่
เริ่มเล่นทันที เลือกรูปลักษณ์/อาชีพเมื่อ Lv.10 กล้องเริ่มต้น 60% ตามคำขอเดิม
Idle เป็นส่วนต่อขยายภายหลัง ไม่เปลี่ยนเกมเป็นการคลิกเมนูและรอพลังอย่างเดียว

## สิ่งที่ทำในรอบนี้
- ใช้ภาพที่ผู้ใช้แนบเป็น key visual หน้าเริ่มเกม พร้อมเก็บต้นฉบับถาวร
- หน้าเริ่มเกม desktop/mobile เปลี่ยนไปใช้สีเงิน/cyan และแผงเครื่องมือสำรวจ
- สีกรอบ HUD, การ์ดเลือกพลัง, HP/EXP, ปุ่มเริ่มและกล้องปรับตาม palette ใหม่
- ระบบต่อสู้ แอนิเมชัน เซฟ อาชีพ และรูปทรงพื้นที่เดินยังทำงานเดิม

## ลำดับผลิตภาพถัดไป
1. ฮีโร่ชาย/หญิงชุดใหม่แบบมือเปล่า แยกถุงมือ/อาวุธ/คู่หู ไม่วาดอาวุธติดตัว
2. ตรวจชุดเดียวกันใน pose guide ยืน/วิ่ง/โจมตี เพื่อไม่ให้เสียงานแก้จังหวะก้าวที่ทำแล้ว
3. Crystal Slime 1 ตัว และผู้พิทักษ์กลไก 1 ตัว ทดสอบอ่านภาพกับฮีโร่ในสนามก่อนผลิตฝูง
4. ฉากเกาะลอยฟ้า 1 สนามพร้อมขอบเขตเดินจริง จากนั้นค่อยเพิ่มหุ่นคู่หูและอาวุธคริสตัล

ภาพ key visual ไม่ใช่ sprite sheet และไม่ใช้แทนฉากต่อสู้ทั้งภาพ งานฉาก/ตัวละครในสนามปัจจุบันยังเป็นชุดเดิมจนกว่าจะผลิตชุดใหม่และตรวจครบ

## การตรวจรอบนี้
