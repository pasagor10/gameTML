# ป่าแห่งสายลม — ฉากเล่นจริง v0.5

## ทำแล้ว
- กล้องเริ่มต้นซูมออก: มือถือขั้นต่ำ .60 จาก .82; จอใหญ่สูงสุด .88 จาก 1.25 เห็นสนามกว้างกว่าเดิมราว 25–30% ตามสัดส่วนจอ
- ปุ่ม − / + / คืนค่าในสนาม ปรับจากค่ามุมกว้างเริ่มต้นได้ 80–150% และจำค่าที่เลือกในเครื่อง
- ฉากใช้ forest-arena ที่เจนไว้และ Slime ใช้ cutout จริง พร้อมเงาและ squash/stretch จากภาพนิ่ง ไม่อ้างว่า Slime มี animation sheet แล้ว
- Elite/บอสใช้ Slime เดิมขยาย เปลี่ยนโทนสี และเพิ่มมงกุฎสำหรับบอส ไม่อ้างว่าเป็นบอส art ใหม่
- พื้นที่เดินกำหนดด้วย polygon ตามแนวลาน ไม่เดินลงลำธารหรือเข้าแนวต้นไม้/ซากกำแพงที่ขอบฉาก ผู้เล่นและศัตรูใช้กติกาเดียวกัน
- ศัตรูเกิดในลานและเว้นระยะจากผู้เล่น แม้ยืนใกล้ขอบ; ปรับกล้องให้หยุดที่ขอบภาพ
- ฉากเป็น background plate หนึ่งชั้นพร้อม ambient glints แยก ไม่มีฉาก 3D/ระบบบังต้นไม้รายชิ้นหรือประตูวาร์ปที่ใช้งานได้ในงานนี้

## Assets และการโหลด
ภาพต้นฉบับ PNG เก็บเดิมไว้ที่ assets/generated/v1
ไฟล์สำหรับเกม: assets/scenes/forest/ground.webp (~592KB), assets/monsters/slime-leaf.webp (~188KB)
สร้างด้วย tools/prepare-scene-assets.py เป็นการแปลง encoding สำหรับส่งให้ browser ไม่มีการเจน/วาดเปลี่ยนต้นฉบับในงานนี้
Slime crop/resample ลง canvas cache ครั้งเดียวก่อนวาดฝูง เพื่อลดภาระการย่อภาพใหญ่ทุกตัวทุกเฟรม
หากไฟล์ภาพโหลดไม่สำเร็จ ยังมี renderer เดิมเป็น fallback และรายงานใน console
