# สไตล์ภาพของ TILMO (v0.13)

ตั้งแต่ v0.13 ทั้งเกมวาดด้วยโค้ด (`src/toon.js` + `src/weapon-paint.js`) ไม่ต้องเจนภาพ แล้วค่อยเกลาให้สวยขึ้นทีละรอบ

- ตัวละคร: ชุดตามอาชีพ (ฝึกหัด / นักดาบ / นักเวท / มือปืน) × รูปลักษณ์ชาย/หญิง × 8 ทิศ (หน้า/หลัง + กลับซ้ายขวา) เดินตามระยะทางจริง
- มอน: สไลม์ ตัววิ่ง ตัวยิงไกล หัวหน้า บอส เปลี่ยนสีและของประดับตามธีมด่าน
- ด่าน: ป่า → ภูเขาไฟ → น้ำแข็ง → วิหารทอง → วังจันทรา → ถ้ำคริสตัล แล้ววนใหม่ (ขอบสนามตรงกับขอบชนจริง)
- อาวุธ: 18 ชิ้น วาดครั้งเดียวแล้วเก็บเป็นภาพในหน่วยความจำ

ภาพเดิม (สไปรต์ตัวละครที่เจน ป่าที่เจน มอนพิกเซลเกมเก่า) ยังอยู่ เปิดได้ด้วย `?art=painted` และกลับมาด้วย `?art=toon` (จำค่าไว้ในเครื่อง)
