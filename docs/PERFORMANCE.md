# TILMO — แก้อาการกระตุก v0.7

## งานที่แก้
- ยกเลิก integer pixel snapping ของฮีโร่: ภาพ HD ใช้พิกัดย่อย โดยเฉพาะเมื่อซูม 60% เพื่อลดการเคลื่อนที่เป็นขั้น
- เตรียมภาพ Slime โทนปกติ/Elite/บอสและแสงตอนโดนโจมตีไว้ก่อน ไม่ใช้ Canvas filter ใหม่กับศัตรูแต่ละตัวทุกเฟรม
- Rasterize ฉากตามระดับซูมครั้งเดียวและใช้ซ้ำ; เก็บ radial glow เป็นภาพเล็ก แทนสร้าง gradient ซ้ำ
- ย้าย vignette ไปชั้น CSS คงที่ ลดงานเต็มจอใน Canvas ทุกเฟรม
- HUD อัปเดตสูงสุด 10 ครั้ง/วินาที แต่การเปลี่ยนสถานะ เช่น เลือกสกิล/แพ้/พัก ยังตอบสนองในเฟรมถัดไป
- ไม่วาดฉากต่อเนื่องเมื่อเปิดหน้าเริ่ม/พัก/เลือกสกิล และหยุดงานเกมเมื่อแท็บถูกซ่อน
- ใช้อาร์เรย์เรียงศัตรูซ้ำ ลด object/closure ที่สร้างต่อเฟรม และข้ามศัตรูที่อยู่นอกมุมกล้อง
- จำกัดความหนาแน่น canvas สูงสุด 2x เตรียม sprite เป็น ImageBitmap หาก browser รองรับ และใช้ opaque game canvas
- รวม floating text ของดาเมจต่อเนื่อง (ไม่เปลี่ยนดาเมจจริง)

กล้องเริ่มต้นยัง 60% จังหวะก้าว ระบบต่อสู้ และค่า damage ไม่ได้ถูกลดเพื่อเพิ่ม FPS

## วิธีวัด
หน้า /src/perf/bench.html เป็นหน้าทดสอบสำหรับผู้พัฒนา แยกจากเกมปกติ
ภาพ 960×540 @1x, seed 42, ฝูง 95 ตัว, ลูกไฟวงโคจร 6 ลูก และ chain lightning
เก็บภาพและอุ่น cache 90 เฟรม จากนั้นเริ่ม fixture ใหม่และวัด 6 วินาทีของเวลาเล่นจริงเหมือนกันทั้ง before/after (update ตาม elapsed time)
ก่อนแก้ใช้ source snapshot ใน src/perf/baseline; หลังแก้ใช้ modules ปัจจุบัน
มี control แบบ requestAnimationFrame เปล่า เพื่อแยกเพดานจังหวะเฟรมของ browser ออกจากงานวาด

ผลเบื้องต้นก่อนแก้ประมาณ 52.4–52.6 FPS, frame p95 ประมาณ 27ms
ผลเบื้องต้นหลังแก้ 75 FPS, frame p95 13.4ms; control เปล่าได้ 75 FPS
ดูผลการวัดขั้นสุดท้ายใน output/performance-comparison.json (fixture และ simulationSeconds บันทึกกับแต่ละรอบ)
เป็นค่าที่วัดใน browser session นี้ ไม่ใช่การรับรอง FPS บนมือถือจริงทุกเครื่องหรือที่ความละเอียด 2x/3x

## ตรวจความถูกต้อง
syntax check และ unit tests 23 ข้อผ่าน รวมกรณี continuous damage 120 ticks ที่ยังเสีย HP เท่าเดิม แต่สร้างเลขลอยน้อยลง
ตัวอย่าง 2 วินาที: ดาเมจ 130 เท่าเดิม จำนวนตัวเลขจาก 120 เหลือ 8 (output/damage-number-allocation.json)

## ตรวจเกมจริง
เปิด /?perf=1 เพื่อดู FPS, frame p95, CPU p95 ในสนาม (ไม่แสดงในเกมปกติ)
การเปิดรอบใหม่/refresh ต้องทำหลังจบรอบที่เล่นค้าง เพื่อใช้ renderer ฉบับใหม่
