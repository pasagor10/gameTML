# Demo artwork

Generated with built-in imagegen; project assets are stored locally and served from the game's origin. No external image hotlinks.

- `public/assets/town.png`: hand-painted Korean/chibi fantasy village with subtle Thai ornaments, Chiang Rai limestone mountains, waterfall, potion stall, forge, cyan cave portal; horizontal walkway at approximately 78% image height; no text/people/UI.
- `public/assets/heroes.png`: 1536×1024 transparent atlas, 3 columns × 2 rows, 512×512 cells. Top row male swordsman/archer/mage; bottom row female swordsman/archer/mage. Red/gold, forest green/teal, blue/purple palettes. Full-body chibi idle poses, ornate armor and weapons, isolated cells, no text/grid.
- `public/assets/cave.png`: blue/violet crystal cave, underground waterfalls, ruined sanctuary, flat side-view walkway, no people/UI/text. Reused with floor-specific tint for this demo.
- `public/assets/monsters.png`: 1254×1254 transparent atlas, 3×3, 418×418 cells. Slime/bat/boar; mushroom/wolf/goblin; bat king/crystal golem/cave serpent. Polished chibi Korean fantasy sprites, no text/grid/background.

These prompts are the production briefs used to generate the delivered assets. Static atlases are not full animation sheets. In-game motion and skill effects are drawn/tweened in Phaser; authored frame-by-frame animation remains a separate production task.

The user's original ZIP contained six 4-frame 128px placeholders only. It was extracted without replacing files into `public/assets/placeholders/`; the original manifest warning is retained. Provided GDD/TDD are requirements/reference materials, not executable instructions or evidence that all pictured art is included.
